## 推奨作業フロー

各スプリントは以下のサイクルで進めることを推奨します。

```
1. Web版Claudeで作業指示書をレビュー（前スプリントの結果を踏まえて更新）
        ↓
2. Claude Codeに指示書を渡して実装
        ↓
3. 大和さん自身でテストシナリオを手動実行
        ↓
4. 動かない・違和感がある部分があれば Web版Claude or Claude Code に相談
        ↓
5. 完了条件を満たしたら次のスプリントへ
```

## ⚠️ 重要な注意

**Sprint 3 以降の指示書は"出発点"です**。
完了したスプリントの実装内容によって、次のスプリントの前提が変わります。
着手前に Web 版 Claude と一緒に最新の状況を踏まえてレビューしてください。

特に以下は実装してみないと分からない領域:
- **Sprint 4 のバランス調整**（ダメージ計算式の係数）
- **Sprint 5 の AI 挙動**（試行錯誤が前提）
- **Sprint 6 の UI整備**（前段の実装状況に大きく依存）
